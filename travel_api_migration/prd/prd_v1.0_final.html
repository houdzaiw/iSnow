iSnow 切换 Travel test API 与启动配置

将 iSnow 当前固定环境和本地登录态启动分流，迁移为 travel 项目的 Bootstrap 启动会话。启动成功后只使用服务端返回的动态 API 基地址，登录和首页通过同一套测试环境完成请求。

一、需求背景

iSnow 原先通过 AppConfig/AppEnv 和 HttpDioManager 固定选择域名；启动页只检查本地登录态。travel 项目则先请求 Bootstrap，解析服务端返回的 API 基地址和混淆路由，再按登录态继续 client.init。

本次以 travel 的 test 材料为唯一启动配置来源，保留 iSnow 现有页面、登录模型和首页 UI，仅替换底层启动流程和公共 API 调用链。

范围边界：本次不替换 WebSocket、H5、CDN、支付等非公共 API；启动配置失败时不得回退旧域名。

测试人员和开发联调人员打开 iSnow 测试包，等待服务端启动配置，完成登录并确认首页数据来自 travel test 服务。

五、详细方案

5.1 启动 Bootstrap 与动态 API 会话

flowchart TD A[启动页] --> B[读取设备身份] B --> C[Travel Bootstrap] C --> D{校验 apiBaseUrl} D -- 失败 --> E[错误页 + Retry] D -- 成功 --> F[保存运行时 Routes] F --> G{本地登录态} G -- 无 --> H[登录页] G -- 有 --> I[client.init] I --> J{成功?} J -- 否 --> E J -- 是 --> K[业务 AES Session]

规则

  • 启动参数原样包含平台、包名、版本、设备 ID、设备品牌、系统语言、App 语言、渠道和 build number。
  • API 地址必须符合当前 test 的协议策略；非法、缺失或解密失败均阻断。
  • Retry 重新执行完整 Bootstrap，不使用旧运行时地址。

5.2 登录与 client.init

sequenceDiagram participant U as 用户 participant P as 登录页 participant S as TravelSession participant API as Test API U->>P: 提交登录信息 P->>S: 调用公共请求 S->>API: Bootstrap 混淆登录路由 API-->>S: token + uid S->>API: client.init API-->>S: crypto 会话材料 S-->>P: 登录完成 P-->>U: 进入首页

规则

  • 保留 iSnow 现有登录 UI 和 LoginResponse 模型。
  • 登录响应成功后立即调用 client.init，成功后才允许登录后公共 API。
  • Token 失效清理本地登录态并回登录页；登录失败保留当前页面提示。

5.3 首页公共 API 加载

flowchart LR A[首页进入] --> B[读取 RuntimeSession] B --> C[AES-GCM 业务信封] C --> D[动态 API Base + Route Token] D --> E{响应成功?} E -- 是 --> F[展示首页数据] E -- 否 --> G[现有错误/空状态] G --> H[不回退旧域名]

规则

  • 首页请求只从内存 RuntimeSession 获取基地址和 crypto 材料。
  • 业务请求携带 Travel 要求的认证头和 v/b 签名。
  • 响应失败可展示现有页面错误状态，但不得重新启用旧 API 地址。

六、业务流程图

完整流程图文件：startup_and_api_flow.md。核心主线是“启动配置 → 动态 API → 登录/client.init → 首页请求”，异常分支为“配置失败 → 错误页 → Retry”，不允许旧域名兜底。

七、异常与边界处理

异常处理
Bootstrap 超时/断网启动页展示错误和 Retry，阻止登录和首页请求。
API 地址缺失或非法判定配置失败，不写入运行会话，不使用旧地址。
client.init 失败配置/网络错误停留错误页；Token 失效清理登录态并进入登录页。
登录失败保留登录页，展示服务端安全错误文案。
首页接口失败使用现有错误/空状态，不回退固定域名。

八、数据追踪与埋点

本次不新增用户行为埋点。debug 仅记录启动阶段、耗时、环境标识、HTTP 状态和业务 code；禁止记录 token、AES key、salt、x-auth-token、完整手机号和请求体。
